M1 screens · direction 2a Ledger

Every screen from the M1 brief in light and dark, with empty, loading, error and long-content states. Sections below run in the order a new user meets them. Earlier rounds live in M1 Directions.

Layout rules

  • A 64px rail on every signed-in screen: workspace, Dashboard and My tasks (later milestones), Projects, project keys with open counts, Settings, you.
  • Lists are tables with column headers. The task detail pane stays open next to the list instead of covering it.
  • Square corners. Only people get round avatars; agents get a cobalt outlined square.
  • Dialogs sit 70 to 140px from the top over a scrim and close with Esc.

Components to build

  • Rail, page header, filter bar, table header, group row, task row, property grid, activity timeline.
  • Buttons (primary, accent, secondary, destructive), text input, select, radio card, checkbox, toggle, kbd hint.
  • Dialog (header, body, footer), error banner, skeleton rows, empty state with CLI hint, code block.
  • Avatar (person, agent), tag, status square, priority glyph, segmented status bar.

Open points

  • The CLI is called pm and keys start with pm_live_ until the product is renamed.
  • Dashboard and My tasks are in the rail but not designed: they belong to later milestones.
  • Comments are reserved below the description; they ship after M1.
  • The sign-in side panel is decoration. Drop it if it reads as live data.
