M5 screens · labels, due dates, blocked by and subtasks

Four task fields added to the existing Ledger screens. The only new tokens are nine label swatches; everything else reuses M1 to M4 tokens. Component styles are in ledger-m5.css. Every frame is shown in light and dark, 1280 wide unless marked 1024. Today in these frames is Tuesday Oct 27, 2026.

Layout rules

  • Label chip: a 7px swatch plus the name, always. Rows show two chips then +N; with the panel open, one chip; at 1024 with the panel open, the Labels column drops.
  • Due date: words carry the state. "3d overdue" is a filled warning pill (the M4 overdue pill), "Due today", "Tomorrow" and the weekday for the next two days are warning text, later dates are quiet, and a done task's past date is faint.
  • Blocked: a barred-circle glyph plus the word, on the danger colours. It counts open blockers only and never blocks a status change.
  • Subtask progress: a 16px bar plus "3/5", canceled excluded. A subtask shows "↳ PAY-142" after its title, which replaces today's "sub of".
  • Panel: Labels gets a full-width cell under the grid; "Created" moves to the header line. Blocked by, Blocks and Subtasks sit between the description and the activity. With none of them, one quiet line offers both.
  • Done blockers are struck (they no longer block). Done subtasks are muted, canceled ones struck.

Calls I made on the brief

  1. Shortcuts: # labels, ⇧D due date, ⇧B add blocker, ⇧S add subtask. They work in the panel, on the focused row or card, and in quick create. L and ⇧L are taken by the board's h/j/k/l moves.
  2. New labels take the least-used colour of the nine. The picker says so.
  3. The label picker also shows near matches while you type a new name ("billing" for "billing-v2").
  4. A new subtask starts as Todo, unassigned, with the parent's milestone and cycle.
  5. The list stays flat. "Nest subtasks" is offered as a view option (frame 6i) and is off by default.
  6. Labels settings sort by most used; a mirrored project's labels can be recoloured (app-side only) but not renamed or deleted.
  7. Dashboard Deadlines: task rows use the calendar glyph, next to the milestone diamond and the cycle circle, sorted by urgency.
  8. On mirrored tasks, Cycle stays editable, as in M3.

Open questions

  1. Labels belong to a project. In My tasks, should the Label filter group labels by project, or merge labels with the same name?
  2. Should My tasks sort by due date by default?
  3. # depends on the keyboard layout. Add a fallback key?
  4. Should a new subtask take the parent's assignee?
  5. Is the strike on done blockers too heavy?
  6. On the dashboard, should a blocked task's due row say "blocked" in its pill? Should a task that is in review and due show in both groups?
  7. Should deleting a label used on many tasks ask you to type its name?
  8. Should colours set in the app ever be written back to Backlog.md files? Assumed no.
