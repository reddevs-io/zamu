The name is always shown in --muted on --surface (7.1:1 in both themes), so colour never carries the meaning alone. The app picks the next unused hue for a new label; slate is the default for labels that arrive from Backlog.md files.

No other new tokens

Due soon, overdue--warn text for today, tomorrow and in 2 days; --warn-bg pill for overdue, the same pill M4 uses for "11 days overdue". Blocked--danger on --danger-bg, always with the word and the barred-circle glyph. Subtask progress--done fill on --track. Mirrored, read-only--hatch as in M3, with "· file" next to the field name. Selection, focus--sel, --focus, --accent unchanged.

Keyboard shortcuts this release adds

Anywhere a task is focused: panel, list row, My tasks row, board card
#Labels picker
ShiftDDue date picker
ShiftBAdd a blocker: search tasks in the project
ShiftSAdd a subtask: pick an existing task or type a new title
In pickers
↑↓Move through the options
EnterToggle a label, pick a date or a task
⌘/CtrlEnterLabels: create the typed name. Subtasks: create a new task with the typed title
TDate picker: today
←→↑↓Date picker: move by a day or a week
PgUpPgDnDate picker: previous or next month
BackspaceDate picker: clear the due date
EscClose the picker, focus goes back to the field
Quick create
#Shift DLabels and due date chips, next to ⇧M and ⇧C. The title field keeps # as text; the shortcuts work once focus leaves it.

Bare L and ⇧L stay with the board's h/j/k/l moves. # is Shift+3 on US layouts; the app listens for the character, so other layouts work too.
