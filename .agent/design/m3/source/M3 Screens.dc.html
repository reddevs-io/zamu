M3 screens · Backlog.md mirror and import

Git connections in workspace settings, a new project settings page with a Backlog.md section, a five-step setup that previews before writing, New project from Backlog.md, the mirrored project in list and board, the mirrored task panel, and detach. Ledger direction; three new tokens in ledger-m3.css. Every frame is 1280×800, light and dark.

How “read-only” reads

  • Fields Backlog.md owns carry a faint diagonal hatch and the word file in their caption. No lock icons: the text says why.
  • A strip above the title names the source file and links to it at the provider.
  • Clicking a hatched field, or pressing ⇧M, opens a short note with the file and a backlog task edit example instead of the picker.
  • Cycle, comments and card order stay editable and look normal.
  • History lines from the mirror use a new actor: “Backlog.md”, a filled square, with the commit hash.

Calls made on the brief

  1. The project settings page replaces the Edit project dialog. The dialog had no room for a Backlog.md section and would duplicate General. Edit in the projects table opens the page.
  2. Mirror status lives in both places: a “Backlog.md” button in the project header opens a popover with state and Refresh now; Settings → Backlog.md has the full detail and the problem list.
  3. Setup is a full page with five steps, not a dialog: the mapping tables and the preview need the width.
  4. In a mirrored project, New is a dashed, disabled button; its tooltip says how to add a task in Backlog.md.
  5. Removed tasks are found through a filter in the bar (“Removed from Backlog.md · Hidden 9”) and a link in settings.
  6. Detach asks you to type the project key.

Decided after review (Oct 23)

  1. New project from Backlog.md is drawn (section 6): repository, connection picked by host, detection, name and key from config.yml and the prefix, mode. It continues at the Mappings step.
  2. The Milestones page of a mirrored project is not drawn. It uses the same hatch on name, date and status, and New milestone is disabled with the same tooltip as New task.
  3. Admins can show the webhook secret again. No rotate in M3.
  4. The app has no status shortcut. The note opens on click, and on ⇧M for the milestone.
