M2 screens · work views

Board, milestones, cycles, comments, My tasks and the theme choice, in the Ledger direction from M1. Every screen in light and dark, with empty, loading, error and long-content states. The M1 screens live in M1 Screens.

Layout rules kept from M1

  • Rail, page header, filter bar, group rows and task rows are unchanged.
  • The task panel is a pane beside the content, never over it. On the board it takes 440px and the board folds Backlog to make room.
  • Square corners. Round avatars for people, outlined squares for agents.
  • Milestones are diamonds, cycles are circles. Neither gets a colour, so status colours stay the only colour coding.

Calls I made on the brief

  • Milestone status: Planned until a task in it starts, then Active. Completed is set by hand.
  • Cycles end on their own at midnight on the end date, and unfinished tasks move to the next cycle. End cycle is for ending early.
  • The theme is saved to the account, not the browser.
  • The full task page gets milestone and cycle as two more rows in its M1 property column. Not redrawn here.
  • Board drag and drop has a keyboard path for every move, plus undo.

Open questions

  • When a cycle ends and no next cycle exists: create one with the same length, or move the tasks out of any cycle?
  • Should a cycle's scope count tasks added after the start (shown with +), or only the tasks planned at the start?
  • Can a person edit or delete an agent's comment if they are its responsible human?
  • Is a Shift+T shortcut for the theme worth having?
