Suggest an agent from Backlog.md assignees

On the Mappings step (and Edit mappings), an assignee like @claude that matches no member and looks like a coding agent gets a suggestion to create the agent. Accepting opens Add agent prefilled, then the one-time key, then the row maps to the new agent. Ledger direction, no new tokens. Every frame is 1280×800.

What stays the same in every option

  • Every unmatched row, agent-looking or not, gets Create agent … at the top of its select menu (1e).
  • A not-yet-created agent is a dashed agent square. Existing agents stay solid-outlined, people stay round.
  • The dialog is the existing Add agent, prefilled: name from the value, you as responsible human, access limited to this project.

Placements

  1. 1a Note under the Assignees table, one line per name. Recommended: next to the rows it fixes, scales to several names, and leaves the tables untouched.
  2. 1b Link inside the row, under the value. Closest to the data; makes rows taller and uneven.
  3. 1c The select shows the suggestion as a dashed value. Compact, but a value that is not yet real can be read as already mapped.
  4. 1d Callout above the tables. Most visible; pushes the tables down and is far from the row.

Open questions

  • Should the note offer “Not an agent” to hide a suggestion? Left out: ignoring it costs nothing.
  • When an agent with a similar name exists (claude-dev for @claude), suggest mapping to it instead of creating? Left out of this pass.
